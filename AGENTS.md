# AGENTS.md

Archviz portfolio + course platform ("Archtipsbox"): Next.js 16 App Router, React 19, TypeScript strict, Tailwind v4, shadcn/ui, Supabase backend. Originally generated by v0.app, deployed on Vercel.

## Commands

Package manager is **pnpm** (`packageManager` pins pnpm@10.10.0); both `pnpm-lock.yaml` and `package-lock.json` exist — use pnpm.

```bash
pnpm dev            # next dev
pnpm build          # next build + prune >25MB files from out/
npx tsc --noEmit    # actual typecheck
```

- `next.config.mjs` sets `ignoreBuildErrors: true` (TS) and `ignoreDuringBuilds: true` (ESLint), so **a passing build proves nothing** about types/lint. Run `npx tsc --noEmit` to verify changes.
- `pnpm lint` runs `eslint .`, but ESLint is not installed and no config exists — the script fails. Don't rely on it.
- No test framework, no CI workflows.

## Gotchas

- **`/public` is gitignored** (.gitignore line 12): images in `public/` are untracked; media was moved to cloud URLs. Files you add there won't be committed.
- Path alias `@/*` maps to the repo root (not `src/`).
- `pnpm build` post-step (`scripts/remove-large-files.js`) deletes files >25MB from `out/` only if that dir exists (legacy Cloudflare Pages limit).
- Env vars per `.env.example`. `NEXT_PUBLIC_*` are browser-exposed; `SUPABASE_SERVICE_ROLE_KEY`, `BAKONG_WEBHOOK_SECRET`, video API keys are server-only — never import them into client code.

## Architecture

- `app/` — routes: portfolio (`/`, `/projects/[id]`), LMS (`/courses/[slug]/[lessonId]`, `/dashboard`, `/certificates/[id]`), commerce (`/pricing`, `/checkout`), admin panel (`/admin`), API routes under `app/api/` (checkout, checkout status, certificate generation) plus `app/auth/callback`.
- `middleware.ts` guards `/dashboard*` and `/admin*`: redirects to `/login` without a Supabase session; admins (via `profiles.role`) get bounced from `/dashboard` to `/admin`; non-admins are bounced from `/admin` to `/`.
- `lib/supabase/db.ts` is the single data-access layer. Every query **falls back to mock data in `lib/projects-data.ts`, `lib/courses-data.ts`, `lib/testimonials-data.ts`** when Supabase is unreachable/unseeded — so pages render without a DB. Keep this pattern for new entities.
- Course access logic (`db.checkCourseAccess`): bypass email list → admin/instructor role → active enrollment → subscription plan hierarchy (higher plan_id unlocks lower-tier courses).
- Payments use Bakong KHQR (`bakong-khqr` pkg): `app/api/checkout/*` creates transactions; `supabase/functions/bakong-webhook/index.ts` is a Deno Edge Function verifying HMAC signatures against `BAKONG_WEBHOOK_SECRET`.

## Supabase

No local CLI setup (no `supabase/config.toml`). Schema is managed by pasting SQL into the remote dashboard:

- `supabase/migrations/schema.sql` + `20260821000000_add_missing_schema_and_tables.sql` — base schema
- `supabase/seed.sql` and `database_seed_instructions.md` — RLS policies + seed data (courses, lessons, exercises, certificates, promo codes)
- After DDL changes, docs run `NOTIFY pgrst, 'reload schema';`

Frontend contracts (TypeScript types, expected DB shapes, endpoint specs) are documented in `structure/` (`data_models.md`, `api_endpoints.md`, `integration_guide.md`).

## Conventions

- shadcn/ui components in `components/ui` ("new-york" style, lucide icons, aliases in `components.json`); add new primitives with the shadcn CLI rather than hand-writing.
- Most components under `components/` are `"use client"` (framer-motion/three.js heavy). Server Components live mainly in `app/`.
- Tailwind v4 CSS-first config in `app/globals.css` (no tailwind.config file); Poppins font via `next/font`.
- `scratch/` holds ad-hoc DB inspection/seeding scripts run outside the app using the service-role key from `.env` — not part of the build.
